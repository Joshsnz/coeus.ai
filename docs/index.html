Coeus AI

A native C++ project-aware AI desktop workspace for working with software projects. Coeus AI combines a custom Skia/SDL2 GUI, local project context, retrieval over codebases, workflow-style runtime operations, structured telemetry, and a private headless evaluation harness used to test repository-grounded behaviour.

Public release scope: this repository is a portfolio/demo package. The full source code remains private, but this public package provides documentation, architecture notes, demo guidance, benchmark reports, release material, and links to the compiled Windows GUI demo.

What this is

Coeus AI was built around the idea that an assistant should understand the currently loaded project, not just answer as a generic chatbot. The app is designed to work against local software projects, inspect project context, retrieve relevant source files, answer repository-aware engineering questions, compare files semantically, and preserve context across follow-up turns.

The goal is not simply to wrap a model in a chat window. Coeus AI explores the application/runtime layer around AI-assisted software work: project state, retrieval, context assembly, tool-style operations, workflow routing, telemetry, and repeatable evaluation.

Why it matters

A common failure mode in AI coding tools is that they sound confident while losing repository context, hallucinating unsupported features, or routing normal codebase questions into the wrong workflow. Coeus AI explores a more structured approach to project-aware assistance.

  • Separate local project inventory from source evidence.
  • Assemble answer context from actual project files.
  • Route different user intents through different workflows.
  • Distinguish semantic repository questions from patch/diff requests.
  • Retain repository context across follow-up turns.
  • Identify absent features without hallucinating implementation.
  • Suppress internal trace/vector/project-storage details from user-facing answers.

Key features

Native desktop GUI

Custom Windows desktop application built with C++20, Skia rendering, and SDL2/OpenGL windowing.

Project-aware assistant

Designed around the active local project, selected context, file inventory, conversation state, and workflow state.

Retrieval and context assembly

Retrieves relevant project files or chunks and assembles context for repository-grounded answers.

Semantic repository QA

Supports architecture questions, source-flow tracing, file responsibility explanations, and semantic comparisons.

Workflow and tool layer

Runtime concepts for command handling, project operations, planning/apply-style flows, task orchestration, and tool routing.

Telemetry and diagnostics

Structured markers and traces support debugging, route analysis, context-packing inspection, and private headless evaluation.

Public / private boundary

Coeus AI is currently presented as a portfolio/demo release. The public repository includes documentation, generated evaluation reports, release material, screenshots/video planning notes, and public-facing project notes.

It does not include the full private source code, private prompts, proprietary runtime internals, private traces, private provider configuration, private project data, or the private headless runner.

This keeps the public package focused on engineering presentation while preserving the private implementation boundary.
