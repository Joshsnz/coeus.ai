# Coeus AI — Short Portfolio Summary

**Coeus AI** is a native C++ desktop AI workspace for project-aware software assistance. It combines a custom Skia/SDL2 GUI, local project retrieval, tool execution, and structured telemetry.

The project demonstrates:

- C++20 native desktop development
- Custom Skia/SDL2 UI engineering
- Project-aware AI assistant workflows
- Retrieval and context assembly over local codebases
- Tool execution and telemetry infrastructure
- Windows build engineering with MSVC, CMake, Skia, SDL2, FAISS, SQLite, OpenSSL, and libcurl
- Runtime design that also supports private/internal non-GUI testing builds

The public repository is a GUI-only portfolio/demo release containing `CoeusAI.exe` and documentation. The full source code and private headless build remain private.
