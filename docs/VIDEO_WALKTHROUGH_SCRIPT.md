# Video Walkthrough Script

## Goal

Create a short 2–4 minute walkthrough showing Coeus AI as a professional portfolio project.

---

## Suggested Script

### 1. Introduction

“This is Coeus AI, a native C++ desktop AI workspace for project-aware software assistance.”

### 2. Native Desktop Interface

“The application uses a custom Skia/SDL2 interface rather than a web UI. The goal was to build a local-first desktop environment for interacting with AI over a software project.”

### 3. Public Demo Scope

“This public release contains the GUI desktop build. The private development environment also has a separate headless build for testing and evaluation, but that is not included in this demo package.”

### 4. Project-Aware Workflow

“Instead of behaving like a generic chatbot, Coeus AI is designed to work with project context: file inventory, retrieval, summaries, evidence, tool output, and runtime state.”

### 5. Evidence and Context

“The assistant can use retrieved project context to answer targeted file questions, architecture questions, comparisons, and recent-change style questions.”

### 6. Tooling and Runtime

“Behind the interface is a modular runtime layer, tool system, retrieval layer, model/provider layer, and telemetry system.”

### 7. Telemetry

“The system records structured telemetry, activity data, and run artifacts so behavior can be inspected and debugged.”

### 8. Closing

“This public release contains the compiled GUI demo and documentation. The full source remains private, but the project demonstrates native C++ application engineering, AI tooling architecture, retrieval systems, and Windows build integration.”
