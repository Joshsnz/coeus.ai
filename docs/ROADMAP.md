# Roadmap

This roadmap describes possible future directions for Coeus AI.

## Short-Term

- Improve release packaging
- Add screenshots and a short demo video
- Improve first-run onboarding
- Improve public documentation
- Add clearer configuration guidance for demo users

## Medium-Term

- Improve project loading workflow
- Improve evidence/context panels
- Expand demo-safe sample projects
- Add signed Windows builds
- Add better crash/error reporting for public demo builds

## Long-Term

- More portable packaging
- Broader provider support
- More automated testing
- Expanded private/internal headless workflows
- More polished public release process

## Notes

The private source version may evolve beyond this public portfolio package. The public release remains focused on the GUI desktop build.
