# FAQ

## What is Coeus AI?

Coeus AI is a native C++ desktop AI workspace for project-aware software assistance.

## Is this a web app?

No. Coeus AI is a native Windows desktop application built with C++, Skia, SDL2, and OpenGL.

## What is the executable called?

The public demo executable is:

```text
CoeusAI.exe
```

## Is the full source code included?

No. This is a portfolio/demo repository. The full source code remains private.

## Is headless mode included?

No. The public release is GUI-only. A separate headless build exists in the private development environment for testing and evaluation, but it is not included in this package.

## Why is the source private?

The project contains proprietary runtime design, internal prompts, implementation details, and development artifacts.

## What does the demo show?

The demo shows a compiled native desktop application and documents the architecture, feature set, build environment, and engineering work behind the project.

## Does it need API keys?

Some AI/model functionality may require provider configuration or API credentials that are not included in the public release.

## What skills does this project demonstrate?

- C++20 desktop application development
- Native GUI engineering
- AI runtime design
- Retrieval and project context systems
- Tool execution architecture
- Telemetry/debugging infrastructure
- Windows build engineering
