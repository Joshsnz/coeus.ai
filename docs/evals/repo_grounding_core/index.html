Benchmark framing

This is a codebase-context benchmark, not a full SWE-bench style autonomous issue-resolution test. It measures whether the app can load a repository and answer useful engineering questions from source files without losing context, inventing unsupported features, misrouting semantic questions into patch/diff mode, or exposing internal trace machinery.

What this benchmark checks

  • Repository bootstrap: creates an isolated project, sets the repo root, and confirms file-context ingest before QA.
  • Source-grounded repository QA: answers questions using current project files instead of generic assumptions.
  • Execution and data-flow tracing: explains cross-file paths such as startup, movement, rendering, and configuration usage.
  • Semantic comparison: compares files by responsibility without misrouting to patch/diff behavior.
  • Negative grounding: correctly says unsupported features are absent instead of hallucinating implementations.
  • Multi-turn continuity: keeps repository context across follow-up turns in the same scenario.
  • Artifact suppression: avoids exposing internal trace, vector, project, or agent storage paths.
